# Georgia Hazard Atlas

The interactive Georgia Disaster Preparedness Map is published through GitHub Pages.

## Website source

Place the uploaded website archive at the repository root with this exact name:

`georgia-disaster-preparedness-map.zip`

The GitHub Actions workflow will extract it, run `npm ci`, build the Vite application for this repository's Pages path, and deploy `app/dist`.

## Public website

https://stever0bat.github.io/Georgia-Hazard-Atlas/

The website is available after the source archive has been committed and the **Build and deploy Georgia Disaster Preparedness Map** workflow completes successfully.
